# ScholarPulse Architecture

## Frozen core

- Scenario A: user-uploaded research papers
- Next.js + TypeScript frontend
- FastAPI backend
- PostgreSQL structured knowledge
- Qdrant vector retrieval
- Redis + Celery for background jobs
- PyMuPDF + Docling extraction
- BGE-M3 embeddings
- BM25 + dense retrieval
- RRF fusion
- BGE-Reranker-v2-M3 reranking
- LangGraph orchestration
- Evidence-grounded RAG
- Cross-paper reasoning on demand

## Milestone 1

Only the infrastructure foundation is implemented here.

Do not add AI dependencies until the base services are verified.
